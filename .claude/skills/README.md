# Skills

每个 skill 一个子目录，目录名即 skill 名。结构：

```
<skill-name>/
├── SKILL.md         frontmatter + 指令
└── reference/       这个 skill 自己的素材（可选）
```

规划中的 skill（按 pipeline 阶段对应）：

| Skill | 对应阶段 |
|-------|---------|
| `domain-focus` | 阶段 0 领域定向（可选） |
| `pain-radar` | 阶段 1 痛点雷达 |
| `score-pain` | 阶段 2 机会评估 |
| `user-research` | 阶段 3 用户研究 |
| `write-prd` | 阶段 4 PRD |
| `design-arch` | 阶段 5 架构设计 |
| `code-tdd` | 阶段 6 编码+TDD |
| `review-tests` | 阶段 7 测试审查 |
| `deploy-monitor` | 阶段 8 部署监控 |
| `ops-growth` | 阶段 9 运营商业化 |
| `pipeline-run` | 元 skill：串起来跑 |
| `pipeline-status` | 看当前 pipeline 状态 |
